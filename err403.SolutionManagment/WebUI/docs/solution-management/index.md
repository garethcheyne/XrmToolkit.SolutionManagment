## What is Solution Management?

Solution Management is an XrmToolBox plugin that lets you transfer solutions between Dynamics 365 and Power Platform environments. Select solutions from a source environment and deploy them to one or more target environments in a single operation.

## Key Features

- **Solution Transfer** — Export from source, import to targets, publish customizations — all automated
- **Multi-target** — Transfer to multiple environments simultaneously
- **Cloud Flows** — View, enable, disable, and manage Power Automate flows
- **Environment Variables** — Compare and transfer environment variable values across environments
- **Platform Settings** — Compare and synchronize organization settings between environments
- **Per-Solution Profiles** — Save different export/import settings for each solution
- **Version Management** — Automatically bump solution versions with configurable policies

## Quick Start

1. Open XrmToolBox and connect to your **source** environment
2. Open the **Solution Management** plugin
3. Click **Add** to connect one or more **target** environments
4. Select solutions and click **Transfer**
