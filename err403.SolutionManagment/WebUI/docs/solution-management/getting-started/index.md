## Overview

This guide walks you through connecting to your Dynamics 365 / Power Platform environments and performing your first solution transfer.

## Prerequisites

- **XrmToolBox** installed and running
- **Solution Management** plugin installed (search "Solution Management (err403)" in the Plugin Store)
- Access credentials for at least two environments (source and target)

> [!NOTE]
> You need sufficient privileges in both the source and target environments to export and import solutions. Typically this requires the System Administrator or System Customizer security role.
